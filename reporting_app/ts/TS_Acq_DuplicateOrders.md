# TS_Acq_DuplicateOrders
This is a daily report for the purpose of checking the purchase orders created the previous business day for ISBN or OCLC matches in FOLIO to evaluate the matches for duplication. The report is usually run the day after the records were created but the next business day may also be several days later (report for Friday is run on Monday) in the case of weekends or holidays. The start report date is for the date the orders were created and defaults to a value of the previous day. The end report date is the date the report is being run and defaults to the current date. The start and end dates can also be entered to create reports for other date ranges; the report will include any records created on the start date up to but not including the end date.

FOLIO matches are found by pulling ISBNs and OCLC numbers the instance records attached to the new orders and then looking for matches on other FOLIO records with the same ISBNs and OCLC numbers. The report excludes matches on the same record (instance attached to the new order matches on itself) and eliminates duplicate matches (the same new order/instance matches on multiple identifiers in one instance.) The same new order/instance may match on multiple records in FOLIO.

The report returns the following fields for new orders: PO number, Instance HRID, vendor code, date PO was created, workflow status, fund code, list price, order format, rush status, title from the POL, publication date from the POL, publisher from the POL, identifier type, raw identifier (includes any related text), identifier (just the ISBN or OCLC number)

The report returns the following fields for the matched records: Instance HRID, title, instance discovery suppressed status, instance status,  instance statistical code, contributors, dates of publication, edition, holdings types, holdings locations.
